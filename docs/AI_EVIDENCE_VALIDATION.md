# P3.2 授权资料证据验收

日期：2026-10-10。P3.2 首轮 TXT/Markdown 解析、确定性术语检索与引用展开已实现。此增量不调用模型，不代表告警 AI 调查、20 案例评估或 P4 已完成。

## 已实现

- 新资料上传在同一事务写入版本、完整片段、解析状态、审计；失败一起回滚。既有资料首次授权查询时按需补建，不重新上传、不覆盖原文件。片段包含版本 ID、ordinal、标题路径、原始行号、SHA-256 与 `text-v1` 解析器版本。
- 查询固定到一个已授权设备，只取该设备及所在工厂的公共资料。取正文前过滤当前发布版本、未归档、工厂和文档角色 ACL；草稿、其他设备、其他工厂及旧发布版本不进入检索。
- 查询和展开均以 actor 的当前 enabled、角色、工厂权限为准，不能依赖 Cookie 旧角色或长生命周期服务的已跟踪用户对象。与发布/撤回/ACL 变更共用工厂事务锁，返回前再校验角色与范围。
- 服务端生成引用路径，绑定设备、文档、版本及片段。换版、撤回、归档或撤权后旧引用不可展开；已保存版本和片段仍保留。HTTP 返回禁止缓存，正文作为纯文本数据返回，不执行 HTML/脚本。
- 文档页显示片段就绪、旧资料待补建、PDF 未解析及不可解析提示。本增量未添加证据搜索表单或告警调查按钮。

接口：

```text
GET /api/v1/assets/{assetId}/document-evidence?query=振动%20coupling&limit=6
GET /api/v1/assets/{assetId}/document-evidence/{documentId}/{versionId}/{chunkId}
```

调用需要真实登录会话；接口不接受 actor/角色/允许工厂列表。返回 DTO 不含存储 key 或上传人。引用 ID 不授予读取权限，也不是完整 AiRun 的 evidence ledger ID。

## 限制与缺口提示

| 项目 | 限制/行为 |
|---|---|
| 单版本解析 | 256 KiB、256 片段、每片段最多 2,000 UTF-16 字符；超限整版拒绝，不静默截断 |
| 文件读取 | 旧资料校验实际文件长度及 SHA-256；读取层限制字节并传递取消；不读取任意路径 |
| 查询 | 最多 200 字符、12 个不同术语；中英文按精确子串忽略大小写匹配，中文词之间可用空格分开 |
| 返回 | 最多 6 片段；按命中数、文档 ID、ordinal 确定性排序；分数只代表相关性 |
| 单次扫描 | 最多 50 份已授权当前资料；超出明确提示结果不完整 |
| 旧资料补建 | 每次最多读取 1 MiB；达到上限提示缺口，下次查询继续补建 |
| 未解析资料 | PDF、空白、超限、不可读、hash 不符均无可引用正文；只对当前授权集合给出通用警告 |

不提供语义/向量搜索、PDF/OCR、复杂 Markdown 渲染或表格理解。解析失败状态保留，不在每次查询无限重试；后续重新索引/解析器升级需另行定义版本契约。
