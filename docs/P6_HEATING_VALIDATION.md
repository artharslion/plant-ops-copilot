# P6.1 原始观测变化与趋势分析

日期：2026-10-28。基线 `bd0b17e` 加本轮工作区；属于 P6.1 的代码增量，不代表完整 P6 或真实模型语义验收。

## 已实现

- 沿用告警点及最多两个同设备候选，每点读取触发前两分钟至触发后一分钟（不晚于 asOf）、当前最近五分钟两个独立 raw 窗口。每窗最多 601 个样本、100 条缺口和 100 段采样配置；超过上限保留截断提示并禁止生成变化结论。重复工具读取复用已登记变化快照。
- `ordered-raw-change-v1` 保存所用样本 ID、有效/接收/源/服务器时间、质量、来源/映射/测点版本、缺口与采样配置。仅在同一版本、Good/有限值、有观测时间、无已知缺口的相邻样本间计算首末值、变化量和按实际有效时间计算的每分钟平均变化率。
- 坏值、不确定质量、接收时间回退、时间异常、溢出、重复有效时间、超间隔、显式缺口和版本未知/变化会断开序列；OPC UA 还要求同一段可验证的 Periodic 配置。Changes/Unknown 不被当作固定周期，不据静默诊断传感器故障。有效的局部段保留，其他点或其他段失败不会抹掉它。
- 非下降观测段允许平台值，至少两次严格增加；最多保留变化量最大的三段。分钟极值、一次突升、跨缺口首末值均不能充当连续升温证据。结果只描述已入库观测段，不保证窗口完整覆盖、物理采样间连续升温、持续超限、共同原因或根因。
- 每个 raw 窗口在独立短数据库快照中读取，保留实际查询时间，过滤有效时间及接收时间晚于 asOf 的样本。查询晚于截止时刻，不声称全部历史都在截止前入库；不在模型调用期间持有事务。
- 新证据 `EventDerivedTrend` / `CurrentDerivedTrend` 的 hash 包括结构化计算输入和输出；持久化及引用展开继续使用原拥有者、工厂和文档权限检查，读取历史调查不重算结果。
- Prompt 为 `investigation-derived-v12`。有原始变化证据的新调查请求 `InvestigationResult.v2`，新增最多三条 `analysis`，需要引用变化证据及所选告警；告警点存在可验证变化时不能仅引用其他点。禁止无依据数字、只复制事实充作分析及确诊/安全结论。无新证据的调用保留 v1 请求与原预算；历史 v1 结果继续可读。语义正确性仍需有限真实模型人工复核，字符串校验不等于语义证明。
- 页面新增可展开引用的趋势分析和计算样本表，支持中英文；工单草稿保留分析及引用，继续由人员确认执行。无需新增数据库迁移，不重写旧调查或提案 hash。
