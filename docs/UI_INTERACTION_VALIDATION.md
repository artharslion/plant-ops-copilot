## 首轮实现范围

- 资产详情采用固定在视口右侧的面板，分为概览、测量、工单、历史及资料；列表保留原位置，各层独立滚动。
- 工单创建/详情、资料上传/详情、目录编辑、告警详情/规则配置、测量配置及调查引用采用同一面板组件。原生 dialog 提供模态层与焦点约束；关闭未保存工单/资料表单时显示放弃确认。
- 离开测量分区即卸载测量组件、清理定时器及订阅；后台测量刷新不反复禁用控件。
- 工单详情后台只核对版本，不清空详情、处理记录或输入，不自动切换到新版本。发现更新后提示重新核对；保留未保存输入，禁止继续用旧版本操作。
- 工单显示五步状态、当前步骤、下一步说明、完成/取消/返工所需输入；取消单独作为流程终止显示。保存后的详情刷新保持面板打开。
- 资料后台响应不会覆盖已开始的元数据编辑或已选文件；告警后台刷新与手动操作的加载状态分离。

## 三步工单续改（2026-10-19）

- 工单步骤条收敛为“创建任务 → 执行维护 → 提交结果”，详情同时显示实际状态。默认“创建并打开”“开始执行”“完成并关闭”；保留“仅保存草稿”和“仅提交完成，留待复核”。取消、返工、过程备注收进折叠区。
- CreateWorkOrder 增加可选 OpenImmediately（默认 false）；TransitionWorkOrder 增加可选 CloseAfterCompletion（默认 false，仅可配合 Completed）。快捷操作复用原状态校验、锁、权限、版本检查和事务；每次内部流转均保留审计，一次提交成功或全部回滚。旧调用默认语义保持不变，无数据库迁移。
- 完成前仍要求处理结果。存在未保存备注时先提示保存；请求失败保留处理结果，不自动重试。
- 重新从运行中的 API 生成前端契约；同时补齐此前生成文件遗漏的已有调查/证据接口类型。
- 浏览器检查发现 /assets 路由与静态资源目录重名，直接访问会重定向后 403；增加两个精确路由回退至应用入口，不改变静态资源路径。
