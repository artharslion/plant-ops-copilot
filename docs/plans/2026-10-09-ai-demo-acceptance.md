# AI 优先的演示项目验收计划

日期：2026-10-09。依据用户明确定位：本项目重点是 AI 接入已有工业业务系统，长期运行容量不是当前交付重点。

## 当前范围与执行顺序

本计划替代旧 P2 计划中 G0 七天满量的开发前置关系。保留阶段编号，执行顺序改为：**P1 已有业务闭环 → P3 AI 只读调查 → P4 人工审批动作 → 按展示需要继续 P2 OPC UA**。

七天满量、第八天滚动、90 天分钟满量、正式 WAL/维护/备份恢复峰值及 30% 容量余量归入可选长期运行验收。状态是“延期、未验收”，不算通过，也不再阻塞 AI 或有限规模演示。旧报告保留为历史证据，其中容量前置条款以本计划为准。

完整 OPC UA 订阅、重连和运维暂缓。已有 SDK、隔离实验、配置、标准化与采样语义成果保留。当前代码继续拒绝业务 OPC UA 启用；新计划不代表 Adapter 已实现。未来有限 OPC UA 演示需独立完成所用协议能力和有限运行控制。

## 核心演示路径

`North Plant → P-101 模拟振动异常 → 告警 → AI 调查 → 展开证据 → 人工创建工单 → 记录结果并关闭`

AI 联合授权设备的趋势、告警、维修工单和已发布资料，输出观察事实、可能原因、验证步骤、缺失信息和引用。质量异常、陈旧和缺口必须展示；模拟数据明确标识来源。

后续 P4 在同一页面增加“生成工单/备注提案 → 人工确认 → 业务服务执行”，独立验收。P3 完成不以 P4 已实现为条件。

## 有限运行验收

| 项目 | 当前必验范围 |
|---|---|
| 种子 | 保留已有 2 工厂、20 设备、100 点位、10 份虚构资料，不删除历史或改种子 |
| 运行窗口 | 单次 10 分钟，最多 100 个 Simulation 点位 × 1 Hz、60,000 条新增 raw；不预填七天数据 |
| 页面与会话 | 两个独立会话完成主路径及角色/工厂隔离，不要求重跑五客户端满量试验 |
| 查询 | 最近 1 小时趋势；列表/概览热查询 p95 < 500 ms，落库到 UI 可见 p95 < 2 s，记录机器与测量口径 |
| 空间 | 运行前记录宿主数据库盘/证据盘余量与既有历史；各盘至少剩余 2 GiB，本轮新增观测消耗每盘不超过 256 MiB，同盘只计一次 |
| 停止 | 达到时限/增长上限、数据库不可用或余量不足，停止本轮采集并保存故障/缺口证据；不清理旧数据换空间 |
| AI | 验证正常、缺资料、坏值/陈旧/缺口、越权、注入、伪造引用、超时/取消/格式失败 |
| 恢复 | 重启后已提交告警、工单和调查可读；模型离线时普通业务可用 |

空间值为演示停止阈值，不是生产容量保证或采样间的硬配额。AI 费用、token、调用次数和超时另按 AI_DESIGN 限制。

使用独立测试 schema/资料目录，保留运行证据和既有数据。原始 7 天、分钟 90 天仍是现有配置，暂不修改；配置不等于对应满量已验收。自动停止/空间控制若需新增实现，应在实验前实现或由验收工具执行，不能把计划当作已有保护。

## AI 优先实施增量

1. **P3.1 Provider 与作业**：PlantOps.AI、ILlmGateway、Fake Provider、AiRun、版本化 schema、取消/超时/预算。先验证 Fake 契约，再选择真实 Provider、配置本地密钥并记录发送范围。Fake 成功不能替代真实模型演示。
2. **P3.2 授权检索**：先解析现有原创 UTF-8 TXT/Markdown，保存版本、标题/片段和 hash；仅检索已发布且当前用户授权的资料。首轮使用确定性术语检索；pgvector/embedding、PDF/OCR 后续增强，不作为前置。PDF 未解析时明确提示。
3. **P3.3–P3.4 调查闭环**：告警页调用带 actor 的只读服务，联合趋势、告警、工单和资料；固定调查设备/工厂范围，登记 evidenceId，校验引用、数值/单位/时间，展示结构化结果和可授权展开的证据。
4. **P3.5 评估**：沿用 AI_DESIGN 的 20 个固定案例，分别报告 Fake 契约和真实 Provider 质量结果；安全案例全部通过，事实均有授权证据，失败明确降级，完成有限运行演示。
5. **P4 动作**：仅创建工单/追加备注，人工明确批准，执行前重授权、版本检查、幂等和事务审计。独立验收后才计入交付。
6. **可选增强**：小规模 OPC UA 闭环、向量检索及 PDF；需要长期运行承诺时再恢复原 G0。
