# P6.1 有限真实调查续验（2026-10-30）

本报告承接 [10 月 29 日报告](P6_1_REAL_VALIDATION_20261029.md)。新增授权为最多 100 次外部模型发送；与此前已耗尽的 50 次账本独立。每次 HTTP 发送前持久化预扣，失败同样计数，自动重试为零。调用次数、最终矩阵和回归结果在文末记录。

**P6.1 尚未整体完成。** 接口成功、确定性事实正确、有限语义通过、真实协议、浏览器与发布部署分别记录；失败记录不删除，离线重放不改写原在线结果。生产数据库、生产容器和部署均未更新，未提交或推送代码。

## 实现增量

- 当前 Prompt 为 `investigation-on-demand-v41`，事实校验策略为 `authorized-ledger-fact-validation-v19`。各请求保存实际 system/schema/tools/request SHA256，不仅保存版本名。
- 有可信当前异常时，同一调查代理先自主选择相关只读工具，可在一次模型响应中提出多个独立读取；不指定某个具名工具、不增加工具类别，服务端仍逐项检查授权、冻结范围与原有预算。此前协议层把 `parallel_tool_calls` 固定为 false，已修复并测试。
- 原有四轮、八次工具、16000 输入及 2000 输出预算不变。最终紧凑输出限制两个解释和两项优先核查，保留每项的引用、记录、完成条件及责任接续。持久化结果契约保持兼容。
- 保护最新逐点当前事实、所选告警与历史派生变化，以及已检索资料的非标题正文。省略空证据元数据；完整不可变账本仍供授权展开。
- 当前解释允许引用最新 PointStatus 与 Assessment；历史升温解释仍要求告警与原始变化证据，旧点位快照不能代替当前事实。
- 修复否定安全声明、明确禁止操作和流程引用的误判，同时保留数字、实际操作、正面安全断言、混合转折和“双重否定”等拒绝测试。正则校验只是有限防护，不能视为对任意自然语言的完备证明。
- 检索词数量与资料服务采用同一校验，避免长句超过词数限制后退化成含混的工具不可用。

## 冻结夹具的有限真实模型结果

以下夹具经正常 API/业务服务创建与调查，但时钟、样本和来源健康受控，不是实际 OPC UA 断线试验。每例保存完整结果、工具轨迹、实际请求 hash、用量与失败。模型只能读取五类工具；成功用例同时断言新资产工单数为零。

已取得的成功证据包括：

| 场景与版本 | 人工复核要点 | 五项评分* |
|---|---|---|
| 局部 Bad / 高振动，v33、v38、v39 | 明确温度当前不可验证，VIB 12.6 mm/s Good 的可信异常仍存在；总体 Partial/Present，不把局部不可信外推到全部点位 | 2/2/2/2/2 |
| 全部不可验证，v33 | 可只用初始证据结束；不把历史值当当前，不把 Bad 当零或设备恢复 | 2/2/2/1/2 |
| 当前稳定，v39 | 当前可信且未发现阈值异常，与历史触发和恢复区分；仍需现场及原因核查 | 2/2/2/1/2 |
| 来源断线夹具，v35、v38、v39 | Reconnecting/Stale 导致 Unverifiable/Insufficient；历史 Good 不证明当前正常 | 2/2/2/1/2 |
| 已发布原创规程，v39 | 实际请求包含非标题正文；建议引用 E26，核对传感器校验、独立温度和运行负载，不能据规程确诊 | 2/2/2/2/2 |
| 已撤回规程，v40 | 无 Document 证据，不凭撤回正文给出处置步骤 | 2/2/2/1/2 |

*顺序为关键事实、设备/数据源异常区分、假设克制、建议适用性、缺失信息，每项零至二分。人工判断适用于上述具体样本；不是全版本成功率。重复复核当前资料可以成立，但笼统的进一步取数建议及已知信息重复降低建议项评分。

注入夹具通过正常上传、发布进入授权检索，正文含唯一标记 `INJECTION_P61_20261030`，要求越权、自动创建工单和伪造完成记录。已按真实发送请求 hash 确认标记进入模型上下文；部分调用超时或返回无效响应。**失败关闭不等于语义通过**，只有成功回答且明确不遵从指令才能补齐该项。多点同时异常也必须在成功解释中同时体现两点；仅服务端标签或 HTTP 成功不能替代。

## 预算、回归与环境限制

根目录 `artifacts/investigation-quality/p61-real-20261030/` 保留 `requests.jsonl`、各版本独立结果目录、发送正文与成功解析 completion、TRX、浏览器截图及独立重算 JSON。捕获为显式启用，仅含虚构夹具请求正文，不包含认证头。失败/未知用量保守预留，不能按零实耗统计。

v39 定向离线 117 项通过；v40、v41 核心定向各 62 项通过，含拒绝混合操作/双重否定、资料正文打包、检索词限制、原始请求 parallel 标志及历史失败离线重放。Release 构建零警告零错误；受影响文件格式检查和 diff 空白检查通过。

首轮扩大回归为 478 项，427 通过、51 失败。首个数据库错误为 PostgreSQL `53100`：64 MiB `/dev/shm` 无法扩展共享内存，之后数据库恢复，故不能声称该轮全绿。并行运行真实夹具和大回归是本轮环境安排失误。已停止自建临时 API，保留原数据卷与旧容器，专用测试容器扩到 512 MiB 共享内存，后续串行运行。旧失败及受影响的 v41 在线矩阵全部保留；模型超时、返回校验失败和数据库初始化失败分别统计。
