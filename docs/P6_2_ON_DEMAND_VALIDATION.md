# P6.2 按需取证最小版与有限验证

日期：2026-10-29。基线 `2cf19c8` 加工作区。该记录覆盖 P6.2 首增量，不代表完整 P5/P6、真实模型温升语义或生产部署验收。

## 已实现

- 初始仅调用设备摘要工具一次，保留所选告警、原始触发快照、最多三个已冻结点位的当前值/质量/来源健康、服务端双维度判断及强制范围提示。趋势、近期告警、维护和资料由模型按需请求。沿用原五个只读工具和严格参数校验；当前测量工具仍一次读取告警点与最多两个同设备候选的固定窗口，尚未提供任意点位/时间参数。
- 每个 lease attempt 保存 `asOf`。当前点位身份、配置及健康冻结；原始样本同时约束有效时间和接收时间。完成分钟统计记录实际查询水位，并明确可能包含截止后迟到的历史观测。维护记录按创建时间过滤，状态和结果只标为读取时版本；截止后发布的文档不参与调查。不能把这些查询追认为截止时已存在的完整历史数据库快照。
- 缓存键覆盖工具名、排序后的参数、截止时间和点位/配置范围 hash；结果记录证据 ID、内容 hash 和实际取数时间。同参数重复调用复用不可变结果，仍计入原工具预算，并重新授权。资料换版、撤权、取消和租约检查继续执行。
- `runRecord` 增加截止时间、取证策略版本和逐调用记录：参数、范围/请求键、开始/结束、缓存命中、成功/不可用/超时/中止及返回证据。调用开始先保存，模型拒绝的工具参数只记录脱敏名称和参数 hash。此记录不是完整 HTTP/逐 token trace。
- 有界工具失败返回未知和脱敏反馈，不把缺失证据解释成设备正常；授权、运行取消与预算错误仍终止调查。新增警告以不可变 DataQuality 条目保存并进入最终页面。初始强制提示和工具失败提示保留在模型输入，较细窗口提示按预算省略并标出数量；完整警告和事实仍在服务端账本及引用展开中。
- 工具取得原始变化后切换 v2 输出与分析约束。后续轮次压缩为单份当前证据投影；服务端事实渲染模式不再要求模型重复接收所有长原始观测，仍保留告警、当前标签及告警点变化依据，最终事实和引用由完整授权账本校验。当前 Prompt 为 `investigation-on-demand-v14`，旧结果及既有提案 hash 不重写。
- 当前评估合并最新的历史窗口快照；工单草稿同一测点只列最新状态。新增质量/范围提示接入中英文展示和工单翻译。

默认 Fake 为确定性工具管道演示，会主动请求四类可选工具；它不证明真实模型能够自主选择工具。专门用例另行验证“无需可选工具即可结束”和“只请求测量”等路径。
